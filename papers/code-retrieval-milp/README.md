# Code Retrieval for MILP Instance Generation

## 基本信息

- **作者**: Tianxing Yang, Huigen Ye, Hua Xu
- **机构**: 清华大学, 北京信息科学与技术国家研究中心
- **arXiv ID**: [2505.11526](https://arxiv.org/abs/2505.11526)
- **代码**: 暂未公开

## 摘要

MILP实例生成通常需要为每个问题类训练单独的模型，计算密集且缺乏灵活性。为解决这些限制，本文将**MILP实例生成任务重新表述为MILP代码生成任务**，通过代码实现高效、灵活和可解释的实例生成。由于代码生成的MILP实例在规模上可能有很大差异，本文引入**MILP-EmbedSim**，一种新的相似性度量，能准确衡量同一问题类内不同规模实例之间的相似性。利用此度量，本文提出**MILP-Retrieval**，一个从库中检索生成代码以产生与目标实例高度相似的MILP实例的管道。MILP-Retrieval在MILP代码生成和实例生成任务上均优于基线方法。

## 核心动机

1. **现有方法的局限性**:
   - 每个问题类需要训练单独的生成模型
   - 训练过程计算密集
   - 生成新实例时缺乏灵活性
   - 难以扩展到新领域

2. **关键洞察**: MILP问题空间比文本、图像或视频等其他模态更小，这使得构建足够大的MILP问题库成为可能

3. **三个核心问题**:
   - Q1: 如何构建足够大的MILP问题库？
   - Q2: 如何从库中检索与目标问题相似的问题？
   - Q3: 为什么这种方法比基于学习的方法更高效？

## 方法

### 1. MILP代码生成任务

将传统MILP实例生成任务重新表述为MILP代码生成任务:

**传统方法**:
- 在特定类的MILP实例数据集上训练模型
- 模型学习重建实例集 $Q = \{q_1, q_2, \ldots, q_m\}$
- 目标: $P$（原始）和 $Q'$（生成）的分布尽可能相似

**代码生成方法**:
- 训练单个统一模型处理多个问题类
- 为测试集 $P$ 生成一段代码 $c$
- 执行 $c$ 直接产生实例集 $Q'$
- 目标仍然是最小化 $P$ 和 $Q'$ 分布之间的差异

**优势**:
- **统一模型**: 无需为每个类训练单独模型
- **计算效率**: 直接生成可执行代码，无需迭代结构预测
- **完全控制问题特征**: 通过调整代码中的参数，可以精细控制生成问题的规模和难度
- **可解释性**: 生成的问题附带相应的数学公式

### 2. MILP库准备

**数据来源**: 使用MILP-Evolve方法生成多样化MILP库

**库结构**: 每个条目包含:
- MILP实例本身
- 生成代码（Python脚本，使用pyscipopt库）
- 对应的二分图表示
- 文本描述（自然语言问题描述）

**两个子库**:
- **Evolve/Train**: 从8个种子类进化而来，4,000个MILP代码和59,033个实例，用于训练
- **Evolve/Test**: 从4个不相交种子类进化而来，50个MILP代码和672个实例，用于测试

### 3. MILP嵌入模型预训练

采用**对比学习框架**（受CLIP启发）:
- 将MILP实例的二分图表示与对应的文本描述对齐
- 使用NV-Embed-V2作为文本嵌入模型
- 使用GNN处理MILP二分图
- 对称交叉熵损失鼓励正确（图，文本）对具有更高相似性

训练目标: 让属于同一问题类但不同规模的MILP实例映射到相似的嵌入

### 4. MILP-EmbedSim: MILP实例相似性度量

**问题**: 现有方法（如Jensen-Shannon散度）依赖少量手动选择的统计指标，只能比较两组MILP问题，无法进行成对比较

**解决方案**: MILP-EmbedSim使用预训练的MILP嵌入模型计算归一化嵌入向量之间的余弦相似性:

$$x_P = \frac{f_\theta(P)}{\|f_\theta(P)\|}, \quad x_Q = \frac{f_\theta(Q)}{\|f_\theta(Q)\|}$$

$$\text{MILP-EmbedSim}(P, Q) = x_P x_Q^T$$

**优势**:
- 支持成对比较
- 能准确评估同一问题类内不同规模实例的相似性
- 对分布外MILP问题具有鲁棒性

### 5. MILP-Retrieval: 代码检索管道

**流程**:
1. 给定目标MILP实例 $p$
2. 使用MILP-EmbedSim从库 $\{(p_i, c_i)\}_{i=1}^N$ 中找到最相似的实例
3. 检索过程: $k = \arg\max_i \text{MILP-EmbedSim}(p, p_k)$
4. 执行检索到的代码 $c_k$ 生成新MILP实例

**两大优势**:
- **无需训练检索**: 不依赖问题特定的模型训练
- **单实例即足够**: 只需一个目标实例即可进行检索

## 实验

### 基准数据集
- **Evolve/Test**: 50个MILP类
- **MIPLIB**: 从MIPLIB基准中选择的三个问题类别（NurseScheduling, CVS, IIS）

### MILP代码生成任务

| 方法 | Code Validity Pass@1 | Pass@4 | Pass@10 | Averaged Similarity |
|------|---------------------|--------|---------|-------------------|
| GPT-4o | 2/50 | 6/50 | 16/50 | 0.444 |
| Finetuned LLaMA 3-8b | 14/50 | 26/50 | 35/50 | 0.271 |
| **MILP-Retrieval** | **50/50** | **50/50** | **50/50** | **0.920** |

MILP-Retrieval在代码有效性上达到100%，相似性分数远超基线。

### MILP实例生成任务

| 问题来源 | 问题类 | MILP-Retrieval | ACM-MILP (η=0.05) |
|----------|--------|---------------|-------------------|
| Evolve/Test | FCNF | 0.819 | 0.435 |
| Evolve/Test | TSP | 0.981 | -0.002 |
| Evolve/Test | GA | 0.842 | 0.015 |
| Evolve/Test | VRP | 0.992 | -0.046 |
| MIPLIB | NurseSched | 0.962 | 0.025 |
| MIPLIB | CVS | 0.822 | 0.129 |
| MIPLIB | IIS | 0.919 | Timelimit |

MILP-Retrieval在几乎所有问题上都优于ACM-MILP基线。

## 关键贡献

1. **任务重新表述**: 首次将MILP实例生成重新表述为MILP代码生成任务
2. **MILP-EmbedSim**: 提出新的MILP实例相似性度量，支持跨规模比较
3. **MILP-Retrieval**: 基于代码检索的高效实例生成管道，无需训练
4. **无需训练**: 与需要大量训练数据的深度学习方法不同，MILP-Retrieval仅需单个目标实例
5. **高效且可扩展**: 利用库的多样性实现鲁棒和可扩展的结果

## 与相关工作关系

- **MILP-Evolve**: 使用其生成的库作为数据来源
- **G2MILP/ACM-MILP**: 作为实例生成基线进行比较
- **CLIP**: 借鉴对比学习思想对齐不同模态
