# MILP-FBGen: LP/MILP Instance Generation with Feasibility/Boundedness

## 基本信息

- **作者**: Yahong Zhang*, Chenchen Fan*, Donghui Chen, Congrui Li, Wenli Ouyang, Mingda Zhu, Junchi Yan
- **机构**: 上海交通大学
- **代码**: Source code will be made publicly available.

## 摘要

机器学习（ML）已被积极应用于线性规划（LP）和混合整数线性规划（MILP），但其潜力受到实例稀缺性的阻碍。当前的合成实例生成方法往往在密切反映原始数据集的分布或确保生成数据的可行性和有界性方面存在不足——这是模型训练中获得可靠监督标签的关键要求。本文提出一个基于扩散的LP/MILP实例生成框架MILP-FBGen。它通过精心设计的结构保留生成模块和可行性/有界性约束采样模块，在结构相似性和新颖性之间取得平衡，同时保持可行性/有界性。该方法在两个方面展示优越性：1）保留LP/MILP实例的关键属性（难度、可行性和有界性）；2）增强下游任务的性能。大量研究表明，该方法在简单和困难数据集上都确保了更高的分布相似性和100%可行性，超越了当前最先进的技术。

## 核心动机

1. **实例稀缺性**: ML在LP/MILP中的应用受限于高质量实例的缺乏
2. **现有方法的不足**:
   - 难以密切反映原始数据集的分布
   - 无法确保生成数据的可行性和有界性
   - 可行性/有界性是获得可靠监督标签的关键
3. **扩散模型的潜力**: 扩散模型在生成任务中表现出色，可用于LP/MILP实例生成

## 方法

### 1. 结构保留生成模块

**目标**: 在生成新颖实例的同时保留原始实例的关键结构特征

**技术**:
- 基于扩散的生成框架
- 结构保留机制确保生成的实例与原始实例在结构上相似
- 在相似性和新颖性之间取得平衡

### 2. 可行性/有界性约束采样模块

**目标**: 确保生成实例100%可行且有界

**技术**:
- 在采样过程中引入可行性约束
- 有界性约束确保目标函数有界
- 保证生成实例的数学有效性

### 3. 扩散模型框架

**前向过程**: 逐步向原始实例添加噪声
**反向过程**: 学习从噪声中恢复实例，同时满足约束条件

## 关键创新

1. **基于扩散的LP/MILP生成**: 首次将扩散模型应用于LP/MILP实例生成
2. **结构保留**: 精心设计的模块在保留结构和生成新颖性之间取得平衡
3. **100%可行性保证**: 可行性/有界性约束采样模块确保所有生成实例可行且有界
4. **适用性广**: 同时适用于LP和MILP实例生成

## 实验结果

- **分布相似性**: 在简单和困难数据集上都实现更高的分布相似性
- **可行性**: 100%可行性保证
- **下游任务**: 生成实例显著提升代表性下游任务的性能
- **超越SOTA**: 超越当前最先进的MILP实例生成技术

## 与相关工作的关系

MILP-FBGen将现有LP/MILP实例生成技术分为三类：
1. **领域知识方法**: 依赖特定方案或公式设计，覆盖面有限
2. **超参数采样方法**: 从超参数编码空间采样构造通用实例
3. **深度生成方法**: 使用深度生成框架破坏和修复原始实例（如G2MILP、DIG-MILP）

MILP-FBGen属于第三类，但通过引入可行性/有界性约束和扩散模型实现了改进。
