# MILP-StuDio: MILP Instance Generation via Block Structure Decomposition

## 基本信息

- **作者**: Haoyang Liu, Jie Wang, Wanbo Zhang, Zijie Geng, Yufei Kuang, Xijun Li, Bin Li, Yongdong Zhang, Feng Wu
- **机构**: 中国科学技术大学, 上海交通大学, 华为诺亚方舟实验室
- **发表会议**: NeurIPS 2024
- **arXiv ID**: [2410.22806](https://arxiv.org/abs/2410.22806)
- **代码**: 暂未公开

## 摘要

MILP-StuDio是一种新颖的MILP生成框架，通过**保留块结构**来生成高质量实例。具体来说，MILP-StuDio首先识别约束系数矩阵（CCM）中的块，并将实例分解为**块单元**（block units），这些块单元作为MILP实例的构建块。然后设计三种操作符（移除、替换、追加块单元）来在原始实例上构建新实例。MILP-StuDio的一个吸引人特点是其在保留生成实例的**可行性和计算难度**方面的强大能力。实验表明，使用MILP-StuDio生成的实例，基于学习的求解器能够显著减少超过**10%**的求解时间。

## 核心动机

G2MILP虽然开创了深度生成MILP实例的先河，但在处理具有块结构的MILP时存在挑战:

1. **破坏块结构**: G2MILP通过迭代修改约束会破坏CCM中的块模式
2. **可行性和难度退化**: 虽然图结构相似性高，但生成的实例可能是不可行的或计算难度严重退化
3. **实例规模限制**: 现有方法难以生成与原始实例不同大小的新实例
4. **生成效率**: 迭代式修改变得耗时，特别是处理大规模实例时

## 方法

### 1. 块结构分解

MILP-StuDio的核心是识别和保留**约束系数矩阵（CCM）**中的块结构:

**三种基本块结构**:
- **块对角（BD）**: $\text{diag}(D_1, D_2, \ldots, D_k)$
- **边界块对角（BBD）**: 在BD基础上添加边界约束
- **双边界块对角（DBBD）**: 更复杂的块结构，具有双边连接

**块分解步骤**:
1. **CCM重排序**: 采用GCG求解器中的结构检测器识别行列置换
2. **块分解**: 基于CCM的图像表示，使用增强变量分区算法提取块单元的子矩阵
3. **约束-变量分类**: 将变量分类为块变量（Bl-Vars）和边界变量（Bd-Vars），约束分类为主约束（M-Cons）、块约束（B-Cons）和双块约束（DB-Cons）

### 2. 结构库构建

从所有训练实例中提取块单元子矩阵，并将其转换为对应的二分图子图:
- 收集这些子图以构建综合**结构库** $\mathcal{L}$
- 结构库作为存储块信息的仓库，便于高效的存储、检索和利用

### 3. 三种块操作符

**缩减（Reduction）**:
- 从原始实例中随机采样一个块单元 $BU_{\text{ins}}$
- 移除该块单元
- 生成规模更小、复杂度降低的实例

**混合（Mix-up）**:
- 从原始实例中随机采样一个块单元 $BU_{\text{ins}}$
- 从结构库 $\mathcal{L}$ 中采样另一个块单元 $BU$
- 用 $BU$ 替换 $BU_{\text{ins}}$
- 引入结构变异和外部块单元的组合

**扩展（Expansion）**:
- 从结构库 $\mathcal{L}$ 中随机采样一个块单元 $BU$
- 将其追加到原始实例
- 生成规模更大、可能引入更复杂结构的实例

### 4. 系数精化算法

在混合和扩展操作中，设计系数精化算法来对齐外部块的系数:
- 将外部块单元的M-Cons系数正确插入原始实例的M-Cons中
- 使用对应的右侧项 $b_i$ 为B-和DB-Cons构建新约束
- 确保块结构的正确性和实例的可行性

## 实验

### 基准数据集
- **组合拍卖（CA）**
- **设施选址（FA）**
- **物品放置（IP）**
- **工作负载分配（WA）**

### 评估指标
1. **图结构分布相似性**: 使用11个经典统计量的Jensen-Shannon散度
2. **计算难度**: Gurobi平均求解时间
3. **可行性比例**: 可行实例占总实例的比例

### 下游任务
1. **增强学习求解器**: GNN分支策略和预测-搜索（PS）框架
2. **传统求解器超参数调优**
3. **困难实例生成**: 迭代生成更难的实例

### 主要结果

| 数据集 | 方法 | 相似性 | 求解时间 | 可行性 |
|--------|------|--------|---------|--------|
| CA | MILP-StuDio (η=0.01) | 0.997 | 0.50s | 100% |
| FA | MILP-StuDio (η=0.01) | 0.663 | 4.94s | 100% |
| IP | MILP-StuDio (η=0.01) | 0.661 | 1000s | 100% |
| WA | MILP-StuDio (η=0.01) | 0.980 | 1000s | 100% |

对比G2MILP:
- 在FA和WA数据集上，G2MILP生成的大部分实例不可行，而MILP-StuDio保持100%可行性
- MILP-StuDio有效保留计算难度，而基线方法严重退化
- 在增强PS求解器方面，MILP-StuDio显著优于其他基线

### 生成效率
- 在WA数据集（超过60,000约束和变量）上，MILP-StuDio实现**3倍加速**相比G2MILP
- 在200小时时间限制内，MILP-StuDio可以完成大规模实例生成

## 关键贡献

1. **块结构保留**: 首次系统性地利用MILP中的块结构进行实例生成
2. **三种操作符**: 设计缩减、混合和扩展操作符实现灵活实例生成
3. **硬度和可行性保持**: 有效保留原始实例的计算难度和可行性
4. **可扩展生成**: 能生成灵活大小的实例，提高实例多样性
5. **生成效率**: 大幅减少生成时间，特别是在大规模实例上

## 与G2MILP的关系

MILP-StuDio是G2MILP的重要后续工作:
- G2MILP开创性地提出深度生成MILP实例
- MILP-StuDio针对G2MILP在处理块结构MILP时的不足进行改进
- 两者共同构成了从数据中学习生成MILP实例的核心方法
