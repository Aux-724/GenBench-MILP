## 摘要

机器学习已成功应用于提高MILP求解器的效率。然而，基于学习的求解器在未见MILP实例上经常遭受严重性能下降——尤其是在来自扰动环境的大规模实例上——这是由于训练分布的多样性有限。为解决这个问题，本文提出一种新颖的方法，称为**对抗实例增强（Adversarial Instance Augmentation）**，用于通过增强图结构来促进学习分支模块的多样性，**不需要知道新实例生成的问题类型**。使用MILP实例的二分图表示，获取各种扰动实例来正则化求解器。通过将**非可微实例增强**表述为**上下文赌博机问题**并对抗性地训练基于学习的求解器和增强策略，实现高效的基于梯度的增强策略训练。本文的**AdaSolver**是第一个理解和改进基于模仿学习（IL-based）和基于强化学习（RL-based）分支定界求解器泛化能力的通用有效框架。

## 核心动机

1. **分布外泛化挑战**: 学习求解器通常在给定数据集上训练，但实践中需要处理规模差异很大的实例
2. **环境变化扰动实例结构**: 例如员工排班问题中，紧急情况导致额外约束，改变问题结构
3. **数据增强的必要性**: 在有限训练域下，获取大量新实例可能不可行
4. **非可微增强的挑战**: 图结构增强通常是非可微操作，难以用梯度方法训练

## 方法

### 1. 实例二分图与分支样本

**MILP实例表示**:
- 每个MILP实例表示为加权二分图 $G = (W \cup V, E)$
- $W$: 变量集，$V$: 约束集
- 每个节点具有特征向量: 约束节点特征 $w_i = (b_i, o_i)$，变量节点特征 $v_i = (c_j, l_j, u_j, \tau_j)$
- 邻接矩阵 $A$ 是约束矩阵，$E$ 表示边的存在

**分支样本**:
- B&B求解器递归求解子问题序列
- 每个子问题也可以表示为二分图
- 引入求解器统计信息（如约简成本和现有值）作为分支样本的特征

### 2. 从鲁棒优化到实例增强

给定分支策略 $\pi$ 和训练实例分布 $p(G)$，构建分布鲁棒训练问题:

$$\min_\pi \sup_{\tilde{p}} \mathbb{E}_{\tilde{G} \sim \tilde{p}(\tilde{G}|G)} L(\pi, \tilde{G}, \mathcal{T}), \quad \mathcal{W}_\mathcal{G}(p, \tilde{p}) \leq \rho$$

其中 $\mathcal{W}_\mathcal{G}(p, \tilde{p})$ 是Wasserstein距离。通过拉格朗日松弛，得到替代损失函数:

$$\varphi(\pi, G, \mathcal{T}) := \sup_{\tilde{G} \in \mathcal{G}} [F(\pi, G, \mathcal{T}) - \beta c(G, \tilde{G})]$$

### 3. AdaSolver框架

AdaSolver包含两个组件:
1. **GNN分支策略网络**: 用于分支变量选择
2. **对抗增强网络（增强器）**: 通过修改MILP二分图表示的结构来模拟真实世界扰动

#### 3.1 实例图增强操作符

通过掩码变量、约束和边来增强实例:
- **变量掩码**: 模拟资源不可用或限制解除
- **约束掩码**: 添加或移除约束
- **边掩码**: 修改变量-约束关系

这些操作符从现实角度也是合理的: 许多MILP问题来自现实世界排班场景，特征变量代表可用工人、机器、车辆等。

#### 3.2 增强的上下文赌博机

**两个关键挑战**:
1. 实例增强通常是非可微过程，难以用梯度训练
2. 增强策略网络接收的训练数据远少于分支策略网络

**解决方案**: 将图增强表述为上下文赌博机问题

- **状态空间** $\mathcal{G}$: MILP实例的图表示
- **动作** $a^{CB} = (V^{CB}, E^{CB}, W^{CB})$: 分别要掩码的变量子集、边子集和约束子集
- **奖励** $r^{CB}(G, a^{CB})$: 分支策略在增强图上收集样本的平均损失

使用**PPO（近端策略优化）**算法的上下文赌博机版本训练增强器。

#### 3.3 增强数据的判别器

**问题**: 对抗增强器倾向于产生与原始分布差异很大的实例（过易或过难）

**解决方案**: 使用判别器网络 $D_\psi$ 识别和移除严重偏离原始分布的实例

- 使用图卷积编码器和MLP解码器实例化
- 图编码器提取MILP实例的结构信息
- 解码器预测实例是否来自原始分布
- 训练目标: $\min_\psi L_D(\psi) = \mathbb{E}_G[D_\psi(\Phi(G))] + \mathbb{E}_G[1 - D_\psi(G)]$

### 4. 训练流程

```
初始化: 学习分支策略 π_θ, 对抗增强器 (Φ_η, V_α, D_ψ)
对于每个epoch:
  随机采样K个MILP实例
  对于每个实例:
    执行增强获得增强实例
    用策略π_η在增强实例上训练
    计算损失
    记录(G, A, Φ_η(a^{CB}_k|G_k))到回放缓冲区
  在回放缓冲区上训练π_θ
  计算L_V(α), L_Φ(η)和L_D(ψ)
  更新参数η, α和ψ
输出: 分支策略参数θ*
```

## 理论分析

### 定理1: IL设置的泛化界

假设损失函数有界且Lipschitz连续，对于IL设置中的数据增强:

$$\mathcal{J}_{p'}(\hat{\pi}) - \hat{\mathcal{J}}_{\Phi(p)}(\hat{\pi}) \leq \mathcal{W}_{\|\cdot\|}(D_{\pi_E, \Phi(p)}(s), D_{\pi_E, p'}(s)) + 2\mathfrak{R}_K^\Phi(\ell \circ \Pi) + \Omega(K)$$

当实例增强拉近训练和测试数据分布时，泛化界更低。

### 定理2: RL设置的泛化界

对于可重参数化的RL设置，类似地推导增强后的泛化界。

## 实验

### 数据集

**四个合成基准**:
- Set Covering (集合覆盖)
- Combinatorial Auctions (组合拍卖)
- Capacitated Facility Location (设施选址)
- Maximum Independent Set (最大独立集)

**真实世界数据集**:
- Anonymous: MIPLIB库的大型实例子集
  - 训练: 98个实例
  - 验证: 20个实例
  - 平均49603个约束和37881个变量

### 规模泛化

| 方法 | D1 | D2 | D3 | D4 | D5 | D6 |
|------|----|----|----|----|----|----|
| **AdaSolver-IL** | 6.28 | 80.67 | 73.78 | 515.92 | 839.80 | 7079.13 |
| GNN | 9.25 | 116.22 | 75.57 | 716.25 | - | - |

AdaSolver-IL在四个合成基准的所有分布上优于所有基线。

### 扰动鲁棒性（真实世界数据集）

| 方法 | Time(s) | Nodes | PD integral | PD gap |
|------|---------|-------|-------------|--------|
| RPB | 866.68 | 43907.95 | 76018.92 | 5.50e+19 |
| GNN | 823.88 | 37469.58 | 45483.01 | 3.50e+18 |
| AdaSolver-RL | 754.08 | 46746.05 | 42179.25 | 5.00e+18 |
| **AdaSolver-IL** | **830.50** | **57156.53** | **42579.31** | **3.33e+18** |

AdaSolver-IL具有最佳的PD积分指标，AdaSolver-RL在真实世界应用中展示了可泛化神经求解器的性能。

### 样本效率

仅使用100个实例（原始数据的1%）训练时:
- 底层GNN性能下降49.70%（Set Covering）和76.45%（Combinatorial Auctions）
- AdaSolver-IL有效缓解性能退化，优于GNN

### 消融研究

- **随机增强（RA）**: 对分布内性能有轻微提升，但无法捕获和产生对泛化到更大概例有用的图结构
- **对抗增强**: 持续在所有指标上表现更好

## 关键贡献

1. **对抗实例增强**: 首个通过对抗性图数据增强促进MILP求解器多样性的框架
2. **上下文赌博机公式化**: 将非可微图增强表述为上下文赌博机问题，实现高效梯度训练
3. **判别器网络**: 防止增强实例严重偏离原始分布
4. **通用框架**: 同时适用于基于模仿学习和基于强化学习的B&B求解器
5. **理论保证**: 提供IL和RL设置下数据增强的泛化界
6. **显著效率提升**: 在规模泛化和扰动鲁棒性方面实现显著效率改进

## 与相关工作关系

- **G2MILP**: 专注于实例生成，AdaSolver专注于实例增强以提高求解器泛化
- **MILP-StuDio**: 同样关注生成高质量实例，AdaSolver从另一个角度（数据增强）提高泛化
- **DHEvo**: 两者都使用进化/增强思想，AdaSolver针对分支策略，DHEvo针对原始启发式
